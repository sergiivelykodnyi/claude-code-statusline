## Original Roadmap: Claude Code Status Line

## Overview

Build the status line inside-out along its risk gradient. Phase 1 delivers everything renderable from the stdin payload alone — model/effort/directory identity, context usage, and both rate-limit segments with countdowns — plus the hide-empty assembly and never-fail error contract every later segment reuses. Phase 2 adds the git segment, the main producer of stateful edge cases, and locks in the render-latency budget. Phase 3 proves the symlink install story on both target environments (macOS host and a live Docker Sandbox) and documents it in the README — at which point v1 is fully shippable. Phase 4 bolts on the isolated, fail-silent Fable weekly `f()` segment, the only feature with an external undocumented dependency, cleanly severable if the endpoint disappears.

## Milestone Summary

**Decimal Phases:** none — all four phases executed in order; Phase 2 absorbed two gap-closure plans (02-03, 02-04) instead of an inserted phase.

**Key Decisions:**

- Single jq `@sh` pass with every one of the 10 stdin fields type-guarded (`strings` / `uint` canonicalizer) — one eval choke point, no bash JSON parsing (Rationale: closes CR-01/CR-02 eval RCEs at one site; bash 3.2 safe)
- Hide-over-placeholder for every segment; never-fail contract (exit 0, zero stderr, line 1 always renders) (Rationale: a blank status line is worse than a sparse one)
- Frame prefixes `╭─ `/`╰─ ` dropped in Phase 2 (layout correction D-21..D-23) (Rationale: bare flush-left lines read better)
- One `GIT_OPTIONAL_LOCKS=0` porcelain-v2 call + `rev-list refs/stash`, uncached, per-marker semantic colors (Rationale: ~12 ms, never takes index locks while Claude runs git)
- Canonical script at `kit/files/home/.claude/statusline.sh`; host `ln -sf`, sandboxes via the `kit/` sbx mixin kit with a root `setup.startup` idempotent `.statusLine` jq merge (Rationale: sandboxes import neither host `~/.claude` nor symlinks)
- Existing sandboxes: `sbx rm` + recreate, not `sbx kit add` (Rationale: sbx v0.39.0 refuses kits with `setup.startup` / `files/`; re-probed every run)
- Fable weekly is a separate last line-2 peer segment `Fable NN%/1w (countdown)` (D-51), sourced stdin `model_scoped` → 300 s 0600 cache → `GET /api/oauth/usage` via `curl -K -` → 3600 s grace → hidden; `STATUSLINE_NO_FABLE` kill switch keeps the harness hermetic
- Every security probe added to `tests/run.sh` must be proven to bite against the pre-fix script (Rationale: string-only probes missed CR-02)

**Issues Resolved:**

- CR-01 `resets_at` → `$(( ))` command injection and CR-02 array-payload eval RCE (Phase 2 gap closure, 14/14 threats closed)
- WR-03 float/exponent stderr leak; WR-04 array probes for all ingested fields
- Docker Sandboxes cannot see host `~/.claude` — solved with the sbx mixin kit + startup merge (Phase 3)
- OAuth usage endpoint shape (`limits[]` `weekly_scoped` entry, `percent` 0-100, ISO `resets_at`) verified live; sandbox credentials observed PRESENT (Phase 4)
- Host `~/.claude/statusline.sh` was a stale regular-file copy — README `ln -sf` line re-run during UAT
