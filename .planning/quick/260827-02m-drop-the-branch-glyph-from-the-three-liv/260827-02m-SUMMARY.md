## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Task 2 gate command needed `-e` for a leading-dash pattern**
- **Found during:** Task 2 verification
- **Issue:** The gate `grep -cF '- \`branch\` — current git branch…'` failed with `ugrep: invalid option`. The local `grep` on this host resolves to `ugrep`, which parses a pattern beginning with `-` as an option. This was a gate-harness defect, not a content failure — the file was already correct.
- **Fix:** Re-ran the full Task 2 battery against `/usr/bin/grep` with `-e` before the pattern. No file content was changed to satisfy the gate.
- **Files modified:** none
- **Commit:** n/a (verification-only)

Note for future plans in this repo: any gate whose fixed-string pattern starts with `-` must use `grep -F -e <pattern>`, and `/usr/bin/grep` is the safer invocation here since `grep` may be shadowed by `ugrep`.
