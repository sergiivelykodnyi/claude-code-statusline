Structure: `cd "$(dirname "$0")/.."` as every test script here does. Define `SRC` as

mutant:
  - `work=$(mktemp -d "${TMPDIR:-/tmp}/statusline-mutation.XXXXXX") || return 1` — never a literal
    path, always quoted, and the later cleanup runs only on a successful mktemp (see the threat
    model below).
  - `cp -R kit tests "$work"/` — the harness `cd`s to its own dirname/.. so a copy of just those two
    trees is self-contained, and `cp -R` preserves the exec bit that `run.sh` asserts on `$SL`.
    Verified at planning time: the copied tree runs the full suite unchanged, and `HERE=${PWD##*/}`
    self-adjusts to the temp directory name.
  - Rewrite the TZOFF line in the copy with `awk`, matching `$0 ~ /^  TZOFF=\$\(tz_offset_secs/`,
    printing the replacement and `next`, passing the replacement in with `-v repl=...`. Do not use
    `sed -i` (BSD/GNU divergence, CLAUDE.md).
  - Applicability guard: `if cmp -s "$SRC" "$work/$SRC"` then the mutation did not apply — report a
    FAIL naming the anchor that moved and stop. `cmp` avoids any regex-escaping of the replacement.
  - Run `/bin/bash "$work/tests/run.sh"` into `"$work/run.log"`, capture the exit status, and count
    mutant-killing lines with `grep -c '^FAIL non-UTC render' "$work/run.log"` piped through
    `tr -d '[:space:]'`.
  - PASS only when the exit status is non-zero AND that count is greater than zero; otherwise FAIL
    with the mutant's own summary tail so the operator sees `N checks, 0 failures` verbatim.
  - `rm -rf "$work"` at the end of the mutant.

Two mutants, in this order:
  1. name `offset dropped`, replacement `  TZOFF=0` — deletes zone handling from the product

  2. name `offset rounded to hours`, replacement

Finish with `printf '%s mutants, %s survivors\n'` and `[ "$FAILS" -eq 0 ]` as the exit status,
