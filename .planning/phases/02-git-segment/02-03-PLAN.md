<objective>
Close the Phase 2 verification blocker: a confirmed command-injection RCE (CR-01) on
the primary interpreter /bin/bash 3.2.57, plus its two supporting warnings.

A hostile rate_limits.*.resets_at value of the form x[cmdsub] flows unvalidated from the
jq @sh/eval boundary into the (( P5_RST - NOW )) / (( P7_RST - NOW )) arithmetic sinks in
seg_5h/seg_1w, where bash 3.2 command-substitutes the array subscript and executes the
embedded command on every render. Reproduced live 3/3 for both rate-limit windows. The @sh
quoting the project relies on for injection safety is bypassed by the arithmetic sink.

This plan enforces numeric type at the single jq boundary (numbers-guard) on every numeric
field, so non-numbers become empty and are skipped by the existing hide-over-empty guards.
The same one-point fix also silences the WR-02 integer-expression-expected stderr leak. It
then extends the test harness so the RCE can never silently pass CI again.

Purpose: eliminate an arbitrary-local-command-execution defect in the shared render/ingestion
path (PORT-02) and its malformed-input degradation (GIT-06), without regressing any verified
Phase 2 behavior.
Output: hardened statusline.sh jq boundary + regression probes in tests/run.sh.
</objective>
