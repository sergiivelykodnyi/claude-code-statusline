## Flagged Assumptions (edge-probe unresolved items — reviewed, not dropped)

The spec-less edge probe left these requirement rows `unclassified`; each was reviewed manually and carries an explicit assumption rather than a silent drop:

1. **SESH-02** — `.effort.level` enum values (low/medium/high/xhigh/max) render verbatim inside parens; an unknown future value also renders verbatim (no validation, no allowlist). Absence is the only hide trigger.
2. **SESH-03** — `workspace.current_dir` is assumed to be an absolute path without a trailing slash (as Claude Code emits it); a pathological trailing-slash value would basename to empty and fall through to the PWD fallback — degraded but never an error.
3. **CTX-01** — `context_window.context_window_size` is assumed present whenever the `context_window` object exists (research A2, binary-verified 200000 default); if a future payload omits it, the context segment hides via its CTX_WIN gate (research Open Question 1 resolution) rather than inventing a window size.
4. **CTX-02** — shortening units are k and M only; there is no G tier because no context window near 1B tokens exists in the verified contract. Values ≥1M render in M units.
5. **LIM-03** — `resets_at` is assumed to be Unix epoch seconds (binary-verified) and the host clock sane; clock skew degrades to a wrong-but-well-formed countdown or `(now)`, never an error.
6. **PRES-02** — ANSI escapes are emitted unconditionally: no tty detection, no NO_COLOR support. Claude Code always interprets SGR (official docs); piping output to a file shows raw escapes by design.
