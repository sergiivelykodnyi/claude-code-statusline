The verified stdin contract always ships both fields together, so this is a defensive posture, not an expected state.
2. **PORT-03** — "Never emits stderr" is proven for every fixture class the verified contract can produce (absent fields, null, empty, malformed, floats, hostile strings). The residual assumption: no unknown payload shape can reach an unguarded arithmetic comparison, because every comparison site guards empty→0 after float truncation and jq is the only other stderr producer (already redirected). The harness's fixture loop is the standing regression for this.
